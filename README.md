##Результаты замера Debug vs Release
| Режим   | Запуск 1 | Запуск 2 | Запуск 3 | Запуск 4 | Запуск 5 | Минимум |
____________________________________________________________________________
| Debug   | 488 мс   | 594 мс   | 612 мс   | 594 мс   | 801 мс   | 488 мс  |
| Release | 356 мс   | 392 мс   | 549 мс   | 564 мс   | 524 мс   | 356 мс  |
В моём эксперименте Release оказался быстрее Debug примерно в
1,37 раза.
Что я обнаружила при сравнении IL:
В Debug присутствуют инструкции, которые отсутствуют в Release:nop, stloc.0, ldloc.0,stloc.1, ldloc.1
Количество IL-инструкций в методе Add() изменилось с 11 до 4.
##Ответы на контрольные вопросы:
1. IL-код - промежуточный код.Он нужен для того чтобы код мог срабатывать на разных процессорах
2. Сборка .NET содержит IL и метаданные, поэтому её часто можно декомпилировать в код, похожий на исходный.
3. В debug было больше инструкций.
4. Release работает быстрее, потому что компилятор удаляет отладочные инструкции и не выполняет лишних команд.
5. Потому что IL и метаданные, которые без проблем можно декомпилировать и узнать пароль.
